# PoE 제작 작업대

Path of Exile 1에서 **원하는 아이템을 만드는 경로와 평균 비용을 비교하는 제작 계산기**입니다.
시작 아이템과 목표 옵션, 사용할 제작법을 정하면 실패 후 복구·재시도까지 포함한 경로를 계산합니다.

[작업대 열기](https://poe-crafting-workbench.pages.dev/) · [Windows 설치](https://poe-crafting-workbench.pages.dev/downloads/PoEWorkbenchSetup.exe) · [업데이트 내역](https://github.com/phoebe7075/poe-crafting-workbench-releases/releases)

## 할 수 있는 일

- **목표 아이템 설정:** 군 주얼과 일반 장비의 베이스·아이템 레벨·옵션·티어를 지정합니다. 장비에는 지원되는 수치 목표도 설정할 수 있습니다. 분열 여부·영향력·빈 접두·접미 자리 등 아이템에 맞게 지원되는 상태 조건을 함께 사용합니다.
- **제작 경로 비교:** 허용한 제작법으로 완성까지 필요한 평균 비용과 재료를 계산합니다. 중간 목표, 필수 단계, IF/ELSE와 AND/OR/NOT 조건으로 제작 방침을 정할 수 있습니다.
- **실패 처리 포함:** 분열 실패품 처분, 새 베이스 구입, 각인 복원 등 지원하는 복구 행동과 비용을 함께 비교합니다.
- **빠른 업그레이드 확인:** 현재 아이템에 선택한 제작법을 한 번 썼을 때의 성공 확률과 추가 비용을 비교합니다.
- **가격과 수익 비교:** 최신·과거 시세, 저장한 가격 세트, 직접 입력 가격을 사용할 수 있습니다. 완성 비용과 새 아이템 기준 수익·위험도를 구분해 표시합니다.
- **조건과 결과 보관:** 계산 당시 입력·가격·완료 기록을 저장하고 비교합니다. 계정으로 다른 기기에서 조회하거나 조건·계산 파일을 내보내고 가져올 수 있습니다.
- **한국어 아이템 입력:** 한국어·영어 아이템 텍스트 붙여넣기와 옵션 선택을 지원합니다.
- **계산 설명 요청문:** 결과의 비용·재료·분기를 담은 짧은 프롬프트를 복사해 설명을 요청할 수 있습니다. 상세 근거와 전체 계산 자료 JSON도 제공합니다.
- **내 PC에 맞는 계산:** 메모리 용량·사용 가능 메모리 비율·동시 계산 수·실행 시간 상한을 설정합니다.
- **문제 신고:** 화면의 ‘문제 신고’에서 내용을 보내고 처리 상태를 확인합니다. 진단 정보는 확인 후 선택해서 첨부합니다.

## 시작하기

1. Windows 설치 파일을 받아 작업대를 설치합니다. Python을 따로 설치할 필요는 없습니다.
2. 처음 실행할 때 계산에 필요한 자료를 준비합니다.
3. 시작 아이템과 최종 목표를 정하고 제작법·가격을 확인합니다.
4. ‘현재 조건 계산’을 눌러 경로를 비교합니다. 수정 중이면 저장하고 계산합니다.
5. 완료 비용, 실패 시 다음 행동, 재료 소모량과 계산 범위를 확인합니다.

**새 계산은 Windows 작업대에서 실행합니다.** 웹에서는 계정에 보관된 조건·가격·결과를 확인할 수 있습니다.
이미 설치했다면 웹의 ‘설치한 작업대 열기’ 또는 Windows 시작 메뉴를 사용하세요.
로그인 없이 이 PC에서 작업할 수 있고, 로그인하면 저장한 자료를 계정과 동기화합니다.

## 지원 범위

Windows 10/11 x64, PoE1 데이터 **3.29.0.4.2** 기준입니다. 군 주얼과 일반 장비를 같은 보관함에서 관리합니다.
기본 화폐, 화석·공명기, 에센스, 제작대, 수확, 야수 제작, 영향력 제작, 퀄리티·기폭제,
타락, 재조합 등에서 해당 아이템과 조건에 지원되는 제작법을 선택할 수 있습니다.

아이템마다 사용할 수 있는 제작법과 계산 가능한 조건이 다릅니다. 지원하지 않는 조합은 이유를 표시합니다.
재조합 등 일부 기능은 명시된 추정 모델을 사용합니다. 결과 화면의 가정과 탐색 범위를 함께 확인하세요.
평균 소모량은 보장 수량이 아니며, 제한 시간 안에서 찾은 경로를 게임 전체의 최저가로 단정하지 않습니다.
시세 갱신과 제작 규칙 업데이트는 별개입니다.

## 업데이트와 계정

다음 실행 때 업데이트를 확인합니다. 실행 중인 계산과 저장 자료는 유지합니다.
새 기기에서 로그인하면 이전 기기의 로그인은 종료됩니다. 비밀번호 복구에는 가입 시 받은 복구 코드를 사용합니다.
이메일 복구와 공개 공유 링크는 현재 제공하지 않습니다. 파일 내보내기·가져오기로 조건과 기록을 전달할 수 있습니다.

PC 설정에서 계산 횟수·오류·버전 통계 공유를 끌 수 있습니다. 아이템 조건과 가격 원문은 사용량 통계에 포함하지 않습니다.
